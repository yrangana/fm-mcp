MCP server · macOS 27 · v0.1.3, public beta

Hand small jobs to the model on your Mac.

fm-mcp lets Claude Code and Codex use the small model built into macOS 27 for the gist of a log, fields from an invoice, or the text in a screenshot. Free, private and offline.

Terminal

$ fm-mcp install    # sets up Claude Code and Codex
$ fm-mcp doctor     # checks everything it needs

01

The model is small, so the agent has to know what not to send it.

Each tool description says what the model gets wrong, with numbers, and fm-mcp install gives each agent a short guide on when to delegate.

brew

One binary

Rust, installed with Homebrew. No Python, no cloning. It starts fm serve when needed and stops it after.

fm-mcp install · doctor

Sets itself up

install writes the Claude Code and Codex config, with backups; --uninstall removes it. doctor checks everything.

skill · AGENTS.md

Says what it can't do

Four narrow tools and no open-ended "ask". Each description states its limits.

03

Four narrow tools

summarise, extract and classify take text or a file path. Full reference: docs/TOOLS.md.

summarise

The gist of a log, document or transcript: a paragraph, or up to 7 bullets.

TakesAbout 30,000 words of prose, or 1,000 lines of a dense log. Long input is split, which is slower and can drop details.

extract

Named fields from one text as JSON, from your JSON Schema. Best with a flat schema.

TakesAbout 3,500 words.

classify

Sorts one text into your labels: one, or several with multi.

TakesAbout 3,500 words.

ocr

Text from a PNG, JPEG, HEIC, TIFF, GIF or BMP image. Not PDF.

TakesOne image.

Good to hand off

  • The gist of a long log or transcript
  • Names, dates, amounts and IDs from a short document
  • Sorting tickets, emails or log lines
  • Text in a screenshot or a receipt photo

Better kept by the agent

  • Code, maths or reasoning
  • Facts the text doesn't contain
  • Anything costly to get wrong that can't be checked
  • A page the agent has already read: nothing to save
04

Where it falls short

The tool descriptions say the same. The notes show how each was measured.

  1. Small context. About 8,000 tokens for input and answer together, and logs use more than twice as many tokens per character as prose.
  2. It makes mistakes. Summaries can drop details. extract can fill a missing field from nearby text: a missing PO number took the supplier's name in 10 of 25 runs. Ask only for fields the text is likely to have.
  3. One request at a time. All sessions share the model, so calls queue. A short extract takes 1–2 s; a long summarise, a minute or more.
  4. Refusals. The model sometimes refuses harmless text. fm-mcp says so, and the agent does the job itself.
  5. Mac only. Apple Silicon and macOS 27 with Apple Intelligence on. No Intel, Windows or Linux.

07 · Privacy

Nothing leaves the Mac

fm-mcp talks to fm serve over a local socket and sends nothing over the network. It reads a file only when the agent passes its path, and writes none. Details in SECURITY.md.
